# 5단계_미응답알림_채점. 미응답 알림과 채점 (기능 4~5)

- 실행: Claude Code, 모드: `acceptEdits`, 소요: 71초
- 실행 위치: C:\Users\oms20\smart-exam (Windows PowerShell)

## 프롬프트 (교안 그대로)

> app.js와 필요한 화면을 수정해서 아래 기능을 추가해 줘.
> 모든 알림은 브라우저 기본 alert가 아니라 화면 가운데 뜨는 알림창으로 만들어 줘.
> 
> [기능04] 답을 선택하거나 입력하지 않고 [Next]를 누르면
> "답을 하지 않으면 모의고사가 진행되지 않아요" 알림과 [확인] 버튼을 보여 주고, 다음 문제로 넘어가지 않게 해 줘. 공백만 입력한 경우도 미응답으로 처리해 줘.
> 
> [기능05] 25번째 문제에서 답을 하고 [Next]를 누르면 25문제를 채점해 줘.
> - 알림창에 "25문제 중 OO문제 정답"과 결과를 표시
> - 18문제 이상이면 pass, 18문제 미만이면 fail
> - [확인]을 누르면 알림창이 닫히게 해 줘
> 
> [단답형 채점]
> 공백을 제거하고 영문 대소문자를 구분하지 않으며, accepted 중 하나와 같으면 정답으로 처리해 줘.
> 
> [채점 검증]
> 정답 수가 17개, 18개인 경우를 코드로 시험해서 fail, pass가 맞게 나오는지 확인해 줘.

## Claude 응답

세 가지 기능을 추가했고, 요청하신 채점 검증도 통과했습니다. 정답 17개는 fail, 18개는 pass가 나옵니다.

## 채점 검증 결과

가짜 화면(DOM)으로 실제 버튼 클릭 흐름을 처음부터 끝까지 재현해 시험했습니다. 객관식 13문제와 단답형 12문제를 섞어 두 채점 방식이 모두 실행되게 했습니다.

| 정답 수 | 알림창 문구 | 결과 |
|---|---|---|
| 17 | 25문제 중 17문제 정답 | fail ✔ |
| 18 | 25문제 중 18문제 정답 | pass ✔ |
| 0 | 25문제 중 0문제 정답 | fail ✔ |
| 25 | 25문제 중 25문제 정답 | pass ✔ |

함께 확인한 것:
- 답 없이 [Next]를 누르면 알림창이 뜨고, 문제 번호가 그대로입니다.
- 단답형에 공백만 입력해도 미응답으로 처리됩니다.
- 단답형 정답을 `E N V I R O N M E N T`처럼 글자마다 띄우고 대문자로 바꿔 입력해도 정답으로 처리됩니다. 정답 수가 정확히 맞아야 통과하는 시험이라 이 처리도 함께 검증됐습니다.
- 알림창에서 [확인]을 누르면 닫힙니다.

## 바뀐 점

- **`index.html`:** 화면 가운데 뜨는 알림창을 추가했습니다(어두운 배경 위 흰 상자, [확인] 버튼). 결과는 pass는 초록색, fail은 빨간색으로 크게 표시됩니다.
- **`app.js`:**
  - [Next]를 누를 때 지금 문제의 답을 저장합니다. 미응답이면 넘어가지 않습니다.
  - 25번째 문제에서 [Next]를 누르면 채점합니다. 지난 단계에서 마지막 문제의 [Next]를 비활성화해 두었던 것은 채점을 위해 없앴습니다.
  - 객관식은 고른 번호와 정답 번호를 비교합니다. 단답형은 공백을 모두 지우고 소문자로 바꾼 뒤 `accepted` 중 하나와 같으면 정답입니다.
- **`style.css`:** 알림창 스타일을 추가했습니다.

**정하지 않은 부분:** 채점 결과 알림창을 닫으면 25번 문제 화면에 그대로 머뭅니다. 이때 [Next]를 다시 누르면 같은 결과가 다시 표시됩니다. 채점 후 화면을 어떻게 할지 지시가 없어서 아무것도 추가하지 않았습니다.
