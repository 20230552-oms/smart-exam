# 6단계_모의종료_기록리스트. 모의종료와 기록 리스트 (기능 6)

- 실행: Claude Code, 모드: `acceptEdits`, 소요: 91초
- 실행 위치: C:\Users\oms20\smart-exam (Windows PowerShell)

## 프롬프트 (교안 그대로)

> 아래 기능을 추가해 줘.
> 
> [기록 저장]
> - 기능05의 채점이 끝나는 순간 localStorage에 한 번만 저장
> - 저장 항목: 날짜(시스템 날짜 YYYY-MM-DD), 회차, 맞춘 개수, pass 여부
> - 회차는 저장된 기록 수 + 1
> 
> [기능06: 모의종료 버튼]
> - 25문제를 끝낸 뒤 누르면: 추가 저장 없이 기록 리스트로 이동
> - 푸는 도중 누르면: "지금 종료하면 안 푼 문제는 오답으로 기록됩니다" 알림과 [확인] [취소]를 보여 줘
> - 푸는 도중 [확인]을 누르면: 지금까지의 답을 채점해 저장하고 기록 리스트로 이동
> 
> [기록 리스트 화면]
> - 표 형식: 날짜 / 회차 / 맞춘 개수(예: 20/25) / pass 여부
> - 최신 기록을 위에 표시
> - 아래에 [새 모의고사 시작] 버튼
> 
> 시작 화면에도 [기록 보기] 버튼을 넣어 줘.

## Claude 응답

기록 저장, [모의종료], 기록 리스트 화면, 시작 화면의 [기록 보기] 버튼을 추가했습니다. 새 테스트와 지난 단계의 채점 테스트(17개 fail / 18개 pass)가 모두 통과했습니다.

## 테스트 결과

가짜 화면(DOM)과 localStorage 대용품(stub)으로 실제 버튼 클릭 순서를 재현했습니다.

| 상황 | 결과 |
|---|---|
| 25문제 완료(18개 정답) | `{"date":"2026-11-13","round":1,"correct":18,"pass":true}` 1건 저장 ✔ |
| 채점 후 [Next]를 다시 누름 | 결과 알림만 다시 뜨고 추가 저장 없음 ✔ |
| 완료 후 [모의종료] | 확인창 없이 기록 리스트로 이동, 추가 저장 없음 ✔ |
| 도중 [모의종료] → [취소] | 6번 문제에 그대로 남고 저장 안 함 ✔ |
| 도중 [모의종료] → [확인] | 회차 2, 6/25, fail로 저장 후 기록 리스트로 이동 ✔ |
| 기록 표 | 최신 기록(2회차)이 위, 1회차가 아래 ✔ |

## 동작 방식

- **저장:** 채점하는 순간 날짜(PC 날짜, YYYY-MM-DD), 회차(저장된 기록 수 + 1), 맞춘 개수, pass 여부를 localStorage의 `smartExamRecords`에 저장합니다. 한 시험에서 저장은 한 번만 됩니다.
- **안 푼 문제:** 도중에 종료하면 안 푼 문제는 오답으로 채점합니다.
- **알림창:** 도중 종료 확인창에만 [확인] [취소]가 함께 나오고, 나머지 알림창은 [확인]만 있습니다.

## 제가 정한 부분

- **도중 종료 시 지금 화면의 답:** 답을 고르고 [Next]를 누르지 않은 채 [모의종료] → [확인]을 누르면, 그 답도 채점에 넣습니다. 고른 답이 오답 처리되면 어색할 것 같아서입니다. [Next]로 넘긴 답만 인정하려면 말씀해 주세요.
- **기록이 없을 때:** 빈 표만 있으면 이상해 보여서 "저장된 기록이 없습니다." 문구를 넣었습니다.
