## 프롬프트 (교안 그대로)

> 스마트공장 수준확인 심사원 시험 대비용 모의고사 웹앱을 만들 거야.
> PC와 스마트폰 브라우저에서 모두 사용할 거고, 시험이 얼마 남지 않아서 단순하고 실용적으로 만드는 게 가장 중요해.
> 
> [기술 조건]
> - 순수 HTML, CSS, JavaScript만 사용 (프레임워크, 빌드 도구, 서버, DB 없음)
> - 파일 구성: index.html, style.css, app.js, questions.js
> - questions.js는 window.QUESTIONS = [...] 형식으로 만들어 index.html을 더블클릭해도 동작하게 해 줘
> - 시험 기록은 localStorage에 저장
> - 화면 문구는 모두 한글
> 
> 지금은 코드를 작성하지 말고, 위 4개 파일의 역할을 짧게 설명한 뒤 내 다음 지시를 기다려 줘.
> 요청하지 않은 기능은 앞으로도 추가하지 마.

## Claude 응답

## 파일별 역할

**1. `index.html`: 화면 구조**
- 앱의 진입점입니다. 이 파일을 더블클릭하면 브라우저에서 바로 열립니다.
- 화면의 뼈대를 담고, `style.css`, `questions.js`, `app.js`를 이 순서로 불러옵니다. 문제 데이터가 먼저 준비돼야 하므로 `questions.js`를 `app.js`보다 먼저 불러옵니다.
- 휴대폰 화면 크기에 맞도록 `viewport` 설정을 넣습니다.

**2. `style.css`: 화면 모양**
- 글꼴, 색상, 버튼, 여백 같은 화면 모양을 정합니다.
- PC와 스마트폰에서 모두 보기 좋도록 화면 폭에 따라 배치를 조정하고, 손가락으로 누르기 쉽게 버튼을 크게 만듭니다.

**3. `questions.js`: 문제 데이터**
- `window.QUESTIONS = [...]` 형식으로 문제 목록만 담습니다. 각 문제에는 문제, 보기, 정답, 해설 같은 항목이 들어갑니다.
- 서버 없이 `<script>` 태그로 불러오기 때문에 더블클릭으로 열어도 동작합니다.
- 문제를 추가하거나 고칠 때는 이 파일만 수정하면 됩니다.

**4. `app.js`: 동작 처리**
- 문제 표시, 답 선택, 채점, 결과 표시 같은 동작을 처리합니다.
- 시험 기록을 `localStorage`에 저장하고 불러옵니다.
- 화면 전환과 버튼 클릭에 따른 동작도 여기서 처리합니다.
