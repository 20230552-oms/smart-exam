## 2. 중복과 화면 폭

- **중복:** 시험 10,000회를 시뮬레이션했고, 매번 서로 다른 25문제가 나왔습니다. 220문제가 모두 고르게 뽑혔고, 문제와 보기가 똑같은 문항도 없습니다.
- **긴 문장:** 가장 긴 문제는 114자(G-098), 가장 긴 보기는 90자(G-092)입니다. 띄어쓰기 없이 가장 길게 이어지는 글자는 55자(G-086)입니다. 화면 폭보다 긴 덩어리도 강제로 줄이 바뀌도록 설정되어 있어서 가로로 잘리지 않습니다.
- **상단 바:** 글자 폭으로 계산하면 `25 / 25`와 버튼 3개를 합쳐 약 310px로, 360px 안에 들어갑니다. 버튼 높이는 44px입니다. 이 값은 계산이고, 실제 측정한 값은 아닙니다.

## 3. 고친 오류

1. **채점 후 결과가 바뀌는 문제:** 채점 뒤 25번 답을 바꾸고 [Next]를 다시 누르면, 알림창에는 새로 계산한 점수가 나오는데 기록에는 처음 점수가 남아 서로 달랐습니다. 이제 처음 저장한 결과를 그대로 보여 줍니다.
2. **저장이 안 되는 환경에서 앱이 멈추는 문제:** 사생활 보호 모드처럼 저장소가 막힌 브라우저에서는 저장 단계에서 오류가 나, 채점 결과 알림창이 뜨지 않고 기록 화면으로도 넘어가지 않았습니다. 이제 저장에 실패해도 결과는 보여 줍니다.
3. **알림창 배경이 일부만 덮이는 문제:** 2021년 이전 iOS(14.5 미만)에서는 알림창의 어두운 배경이 화면 전체를 덮지 못했습니다. 지원 범위가 넓은 방식으로 바꿨습니다.

1번과 2번은 회귀 테스트(고친 동작이 다시 망가지지 않는지 확인하는 테스트)를 추가해 통과했습니다. 이 밖에 긴 내용이 영역을 밀어내지 않도록 CSS를 조금 보강했습니다.

## 4. Netlify Drop으로 올려 스마트폰에서 접속하기

**① 무료 가입하기 (권장)**
1. PC 브라우저에서 **https://app.netlify.com/drop** 에 접속합니다.
2. 가입하지 않아도 올릴 수는 있습니다. 하지만 이렇게 올린 사이트는 잠시 뒤 지워질 수 있으니 **Sign up**으로 무료 가입을 먼저 하세요. Google 계정으로 가입하면 간단합니다.

**② deploy 폴더 올리기**
1. 파일 탐색기에서 `C:\Users\oms20\smart-exam`을 엽니다.
2. 안에 있는 **`deploy` 폴더를 통째로** 끌어다가 Netlify 화면의 점선 상자("Drag and drop your project folder here")에 놓습니다. 파일 4개를 따로 끌지 말고 폴더째 끌어야 합니다.
3. 몇 초 기다리면 `https://임의이름.netlify.app` 같은 주소가 나옵니다. 이 주소가 앱 주소입니다.
4. 주소를 클릭해 PC에서 먼저 열리는지 확인합니다.
5. (선택) **Site configuration → Change site name**에서 주소 앞부분을 외우기 쉬운 이름으로 바꿀 수 있습니다.

**③ 스마트폰에서 열기**
1. 주소를 카카오톡 "나에게 보내기" 등으로 휴대폰에 보냅니다.
2. 휴대폰에서 주소를 누르면 바로 열립니다.
3. 홈 화면에 아이콘을 만들어 두면 앱처럼 쓸 수 있습니다.
   - 아이폰(Safari): 아래쪽 공유 버튼 → **홈 화면에 추가**
   - 안드로이드(Chrome): 오른쪽 위 ⋮ → **홈 화면에 추가**

**④ 앱을 고친 뒤 다시 올리기**
1. 고친 파일을 `deploy` 폴더에 다시 복사합니다.
2. Netlify에서 내 사이트 → **Deploys** 탭으로 갑니다.
3. `deploy` 폴더를 다시 끌어다 놓으면 같은 주소로 바뀐 내용이 반영됩니다.

**알아 둘 점**
- 시험 기록은 기기와 브라우저마다 따로 저장됩니다. PC 기록이 휴대폰에 보이지 않습니다.
- 브라우저의 사이트 데이터를 지우면 기록도 지워지고, 사생활 보호 모드에서는 기록이 남지 않습니다.
- 주소를 아는 사람은 누구나 접속할 수 있습니다.

배포한 뒤 휴대폰에서 상단 버튼 3개와 긴 문제(예: G-098, G-092)가 잘리지 않는지 한 번 확인해 주세요. 실측을 못 한 부분이라, 문제가 보이면 바로 고치겠습니다.
