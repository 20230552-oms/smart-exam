# 2단계_PDF_문제변환. PDF를 문제 데이터로 변환

- 실행: Claude Code, 모드: `acceptEdits`, 소요: 257초
- 실행 위치: C:\Users\oms20\smart-exam (Windows PowerShell)

## 프롬프트 (교안 그대로)

> gemini.pdf와 claude.pdf를 읽어서 220문제 전체를 questions.js로 만들어 줘.
> 
> [구성]
> - gemini.pdf: 객관식 100문제, 뒤쪽 정답표 사용, 해설 없음
> - claude.pdf: 객관식 100문제 + 단답형 20문제, 뒤쪽 정답·해설 사용
> 
> [데이터 형식]
> 객관식:
> { "id":"G-001", "type":"choice", "question":"문제", "options":["보기1","보기2","보기3","보기4"], "answer":2, "explanation":"" }
> 단답형:
> { "id":"S-001", "type":"short", "question":"문제", "answer":"3년", "accepted":["3년","3"], "explanation":"" }
> 
> [규칙]
> - id: gemini 객관식은 G-001~G-100, claude 객관식은 C-001~C-100, claude 단답형은 S-001~S-020
> - answer는 객관식 정답 번호 1~4 (①=1)
> - 문제 문장이나 보기가 줄바꿈으로 끊긴 곳은 자연스럽게 이어 붙여 줘
> - 한 줄에 붙어 있는 ①②③④ 보기는 4개로 분리해 줘
> - 머리글, 페이지 번호, 영역 제목, 안내문, 응원 문구는 문제에 포함하지 마
> - 문제와 보기의 내용은 임의로 고치거나 요약하지 마
> - claude.pdf의 해설은 explanation에 넣어 줘. 해설 끝의 근거 표시(규정, 공고, 표준, 일반)는 빼 줘
> - accepted에는 같은 뜻의 답을 넣어 줘
>   예: "5명(5인)" → "5명", "5인", "5"
>   예: "1,000점" → "1,000점", "1000점", "1000"
>   예: "AI(인공지능) 기능" → "AI", "인공지능", "AI 기능", "인공지능 기능"
> 
> 완료 후 변환된 문제 수를 알려 줘.
