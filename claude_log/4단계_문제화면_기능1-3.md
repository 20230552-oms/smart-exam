# 4단계_문제화면_기능1-3. 문제 화면과 기능 1~3

- 실행: Claude Code, 모드: `acceptEdits`, 소요: 77초
- 실행 위치: C:\Users\oms20\smart-exam (Windows PowerShell)

## 프롬프트 (교안 그대로)

> index.html, style.css, app.js를 만들어 줘.
> 
> [기능01] 앱을 열면 시작 화면과 [모의고사 시작] 버튼을 보여 주고, 시작하면 220문제에서 중복 없이 25문제를 무작위로 뽑아 줘.
> 
> [기능02] 한 화면에 한 문제만 보여 줘.
> - 객관식: 라디오 버튼 4개. 보기 글자를 눌러도 선택되게 해 줘
> - 단답형: 텍스트 입력칸
> 
> [기능03] 화면 구성
> - 상단 바 왼쪽: 현재 문제 번호 (예: 3 / 25)
> - 상단 바 오른쪽: [답 확인] [Next] [모의종료] 버튼
> - 상단 바 아래 남은 화면에서 위쪽 2/3는 문제 영역, 아래쪽 1/3은 답 확인 영역
> - 내용이 길면 각 영역 안에서 스크롤되게 해 줘
> - [답 확인]을 누르면 답 확인 영역에 정답을 보여 주고, 해설이 있으면 함께 보여 줘
> - [Next]를 누르면 다음 문제로 이동하고 답 확인 영역을 비워 줘
> 
> [UI]
> - 일반적인 웹 서비스처럼 흰 배경의 깔끔한 스타일
> - 스마트폰 화면(폭 360px)에서도 버튼 3개가 잘리지 않고 손가락으로 누르기 쉽게
> - 높이는 모바일 주소창을 고려해 100dvh 사용
> 
> [모의종료] 버튼은 이번 단계에서는 자리만 만들어 줘.

## Claude 응답

`index.html`, `style.css`, `app.js`를 만들었습니다. 다만 폭 360px 화면에서 버튼 3개가 잘리지 않는지는 아직 눈으로 확인하지 못했습니다. 이 세션에서 작업 폴더 밖의 Edge를 실행할 수 없었기 때문입니다.

**확인한 것:** Node에 가짜 화면(DOM)을 만들어 25문제를 끝까지 넘기는 흐름을 4번 돌렸고, 모두 오류 없이 통과했습니다.
- 시작 버튼을 누르면 시험 화면으로 바뀌고, 25문제가 중복 없이 뽑힙니다.
- 상단에 `1 / 25` ~ `25 / 25`가 올바르게 표시됩니다.
- [답 확인]을 누르면 정답이 나오고, 해설이 있으면 함께 나옵니다. [Next]를 누르면 답 확인 영역이 비워집니다.
- 객관식과 단답형 두 화면이 모두 실행됐습니다. 단답형은 무작위라 0~3문제씩 섞였습니다.

**만든 내용**
- **화면 구성:** 상단 바 아래를 문제 영역 2/3, 답 확인 영역 1/3으로 나눴고, 내용이 길면 각 영역 안에서 스크롤됩니다. 높이는 `100dvh`를 쓰고, 이를 지원하지 않는 브라우저에서는 `100vh`로 대신합니다.
- **보기 선택:** 보기 글자를 포함한 칸 전체가 라디오 버튼 라벨이라, 어디를 눌러도 선택됩니다.
- **360px 대비:** 버튼 높이를 44px로 하고 줄바꿈을 막았습니다. 계산상 `25 / 25`와 버튼 3개가 약 340px 안에 들어갑니다.
- **[모의종료]:** 요청대로 버튼 자리만 있고 아직 동작은 없습니다.
- **답 확인:** 정답만 보여 주고, 내가 고른 답이 맞았는지 채점하지는 않습니다(요청하지 않은 기능이라 넣지 않았습니다).

**제가 정한 부분:** 마지막 25번 문제에서는 [Next]를 비활성화했습니다. 다음 문제가 없을 때 어떻게 할지 따로 지시가 없어서, 아무 일도 일어나지 않도록 막아 두었습니다.

**직접 확인 부탁드립니다:** `index.html`을 더블클릭해 PC 브라우저에서 개발자 도구(F12)의 모바일 보기를 폭 360px로 맞추거나 휴대폰으로 열어, 상단 버튼 3개가 잘리지 않는지 봐 주세요. 잘리면 버튼 크기를 조정하겠습니다.
